# ИИ-сервисы только через VPN

ChatGPT, Claude, Gemini, Perplexity, Grok, Hugging Face и другие ИИ-сервисы всегда идут через VPN, даже если рядом включено «Россия напрямую».

Правило `proxy` стоит выше `direct`, поэтому эти домены идут через VPN, даже если они подпадают под прямые правила других плагинов.

Установка: Tunn → Настройки → Плагины и ядра → добавить плагин → файл `dist/tunn-ai-via-vpn-1.0.0.zip` или ссылка на него.
