# Торрент-клиенты мимо VPN

Торрент-клиенты исключаются из VPN: не загружают туннель и не расходуют трафик подписки.

Раздача и загрузка идут с вашим настоящим IP. Включайте, только если это нужно именно вам.

Установка: Tunn → Настройки → Плагины и ядра → добавить плагин → файл `dist/tunn-torrents-direct-1.0.0.zip` или ссылка на него.
