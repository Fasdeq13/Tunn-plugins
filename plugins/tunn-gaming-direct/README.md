# Игровые загрузки напрямую

Загрузка игр из Steam, Epic, Battle.net, Riot идёт мимо VPN на полной скорости провайдера: не тратит трафик VPN и не упирается в его скорость.

Касается только серверов загрузки. Авторизация и магазин остаются через VPN, поэтому региональные ограничения вашего аккаунта не меняются.

Установка: Tunn → Настройки → Плагины и ядра → добавить плагин → файл `dist/tunn-gaming-direct-1.0.0.zip` или ссылка на него.
