# Tunn-plugins

Официальные плагины для [Tunn](https://github.com/Fasdeq13/FasdeqVPN). Каждый плагин лежит двумя способами:

- `plugins/<id>/` — исходники (`plugin.json` и описание);
- `dist/<id>-<версия>.zip` — готовый архив для установки.

Плагины ничего не меняют в коде Tunn и не требуют пересборки приложения: ставятся из файла или по ссылке. Нужен Tunn 4.0 или новее.

## Установка

Tunn → Настройки → Плагины и ядра → добавить плагин → выбрать `.zip` из `dist/` или вставить ссылку вида
`https://github.com/Fasdeq13/Tunn-plugins/raw/main/dist/tunn-ru-direct-1.0.0.zip`.
Затем включите плагин в списке; значения полей (свои домены, приложения) задаются в его настройках.

## Плагины

| Плагин | Что делает |
| --- | --- |
| `tunn-ru-direct` | Российские TLD и сервисы (Яндекс, VK, Mail.ru, 2ГИС…) и локальные сети идут мимо VPN |
| `tunn-ru-apps` | Банки, Госуслуги, маркетплейсы и такси целиком исключаются из VPN |
| `tunn-ad-shield` | Блокировка рекламных сетей и трекеров по доменам |
| `tunn-ai-via-vpn` | ChatGPT, Claude, Gemini и другие ИИ-сервисы всегда через VPN |
| `tunn-gaming-direct` | Загрузки Steam, Epic, Battle.net, Riot идут напрямую |
| `tunn-torrents-direct` | Торрент-клиенты исключаются из VPN |
| `tunn-messengers-only` | VPN только для мессенджеров, остальное напрямую |
| `tunn-local-network` | Роутер, NAS, принтеры и Chromecast доступны при включённом VPN |
| `tunn-telemetry-block` | Блокировка телеметрии производителей и аналитики приложений |

Плагины правил складываются: все включённые плагины объединяются в один набор. Порядок применения в Tunn: **блокировка → через VPN → напрямую**. Поэтому `tunn-ai-via-vpn` перекрывает «Россия напрямую», а `tunn-ad-shield` перекрывает всё. `tunn-messengers-only` — белый список приложений и не сочетается с плагинами «мимо VPN».

## Темы

`themes/*.json` — оформление всего приложения (палитра, скругления, стиль карточек и переключателей). Tunn → Настройки → Оформление → Темы-плагины → Установить тему из файла. Формат: `plugins/THEMES.md` в основном репозитории.

## Сборка и проверка

    python3 tools/build.py        # проверка manifest'ов по правилам установщика Tunn, сборка dist/*.zip и index.json
    python3 tools/test_plugins.py # повторяет слияние правил Tunn и проверяет итоговый набор

Архивы собираются воспроизводимо (фиксированные даты), CI проверяет, что `dist/` и `index.json` соответствуют исходникам. В `index.json` лежат размеры и SHA-256 архивов.

## Свой плагин

Скопируйте любую папку из `plugins/`, поменяйте `id` (равен имени папки), правила и настройки, запустите `tools/build.py`. Формат manifest'а — `plugins/README.md` основного репозитория. Нативные плагины протоколов (`.so`) и JS-плагины интерфейса здесь не публикуются: JS-интерфейс работает только в старом WebView-UI, а `.so` собирается под Android NDK отдельно.

Плагины выполняют правила маршрутизации в вашем VPN-трафике. Ставьте только из источников, которым доверяете.
