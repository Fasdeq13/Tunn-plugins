# Домашняя сеть напрямую

Роутер, NAS, принтер, телевизор и Chromecast остаются доступны при включённом VPN: локальные адреса и имена .local/.lan идут напрямую.

Только маршрутизация. Чтобы ещё и открывались ссылки на локальные имена, DNS должен уметь их разрешать.

Установка: Tunn → Настройки → Плагины и ядра → добавить плагин → файл `dist/tunn-local-network-1.0.0.zip` или ссылка на него.
