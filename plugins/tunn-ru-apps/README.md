# Банки и госуслуги мимо VPN

Приложения банков, Госуслуги, маркетплейсы и такси исключаются из VPN целиком: банки часто блокируют вход с иностранного IP.

Список пакетов — лучшая попытка: если приложения нет на телефоне, запись игнорируется. Нужный пакет можно добавить в настройках плагина. Действует при режиме приложений «Все» или «Кроме выбранных».

Установка: Tunn → Настройки → Плагины и ядра → добавить плагин → файл `dist/tunn-ru-apps-1.0.0.zip` или ссылка на него.
