# Блокировка рекламы и трекеров

Блокирует известные рекламные сети, счётчики и SDK-трекеры на уровне домена для всех приложений.

Работает по доменам: запрос к рекламному домену получает отказ ещё до соединения. Реклама, встроенная в тот же домен, что и контент (например, в видео YouTube), не блокируется. Если что-то перестало работать, отключите плагин.

Установка: Tunn → Настройки → Плагины и ядра → добавить плагин → файл `dist/tunn-ad-shield-1.0.0.zip` или ссылка на него.
