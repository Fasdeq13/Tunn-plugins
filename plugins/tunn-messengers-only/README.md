# Только мессенджеры

VPN работает только для Telegram, Discord, WhatsApp, Signal, Viber и выбранных вами приложений. Всё остальное идёт напрямую.

Режим «белого списка»: в VPN попадают только перечисленные приложения. Работает, если в настройках приложений Tunn выбран режим «Все». Не включайте вместе с плагинами «мимо VPN» — они противоположны по смыслу.

Установка: Tunn → Настройки → Плагины и ядра → добавить плагин → файл `dist/tunn-messengers-only-1.0.0.zip` или ссылка на него.
