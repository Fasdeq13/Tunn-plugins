# Россия напрямую

Российские сайты и сервисы (.ru, .su, .рф, Яндекс, VK, Mail.ru, 2ГИС и др.) и локальная сеть идут мимо VPN: быстрее, и не ломаются сервисы, которые блокируют зарубежные адреса.

Правила: российские TLD и крупные российские сервисы напрямую. Домены из поля «исключения» идут через VPN (правило `proxy` выше `direct`).

Установка: Tunn → Настройки → Плагины и ядра → добавить плагин → файл `dist/tunn-ru-direct-1.0.0.zip` или ссылка на него.
