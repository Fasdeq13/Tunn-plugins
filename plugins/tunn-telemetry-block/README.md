# Блокировка телеметрии

Режет телеметрию производителей телефонов (Xiaomi, Samsung) и аналитику приложений (Crashlytics, Mixpanel, Amplitude, Sentry).

Приложения продолжают работать, но не отправляют статистику и отчёты о сбоях. Если приложение при запуске зависает на загрузке, отключите плагин.

Установка: Tunn → Настройки → Плагины и ядра → добавить плагин → файл `dist/tunn-telemetry-block-1.0.0.zip` или ссылка на него.
